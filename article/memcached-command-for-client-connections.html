Memcached Command for Client Connections

This guide explains how to view active and historical client connection statistics in Memcached using the built-in administrative interface. By querying the server with the stats command, administrators can extract real-time metrics on open connections through curr_connections as well as the cumulative historical connection count through total_connections.

The Command: stats

Memcached provides connection details through the general stats command. Within the output generated by this command, two specific metrics track client connection activity:

  • curr_connections: The total number of currently active, open client connections.
  • total_connections: The historical total of all client connections opened since the Memcached process started.

How to Run the Command

You can retrieve these metrics from the command line using tools such as netcat (nc) or telnet.

Using Netcat (nc)

Run the following command in your terminal, replacing 127.0.0.1 and 11211 with your Memcached host and port if different:

echo "stats" | nc 127.0.0.1 11211 | grep -E "curr_connections|total_connections"

Example Output

STAT curr_connections 12
STAT total_connections 154820

Using Telnet

  1. Connect to the Memcached instance:

    telnet 127.0.0.1 11211

  2. Type stats and press Enter.

  3. Look for the STAT curr_connections and STAT total_connections lines in the returned output.

  4. Type quit and press Enter to close the session.
