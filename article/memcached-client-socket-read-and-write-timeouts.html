Memcached Client Socket Read and Write Timeouts

When communicating with Memcached, network anomalies or overloaded servers can cause client connections to hang indefinitely if socket limits are not enforced. This article outlines the specific parameters and configuration options used to govern socket read and write timeouts across the most common Memcached client libraries in Python, PHP, Java, Go, and Node.js.

PHP (ext-memcached)

The official PECL Memcached extension exposes underlying libmemcached behaviors through integer constants set via Memcached::setOption().

  • Memcached::OPT_SEND_TIMEOUT: Controls the socket write timeout in microseconds.
  • Memcached::OPT_RECV_TIMEOUT: Controls the socket read timeout in microseconds.
  • Memcached::OPT_CONNECT_TIMEOUT: Controls the initial socket connection timeout in milliseconds.
$mc = new Memcached();
$mc->setOption(Memcached::OPT_CONNECT_TIMEOUT, 1000); // 1 second
$mc->setOption(Memcached::OPT_SEND_TIMEOUT, 1000000); // 1 second
$mc->setOption(Memcached::OPT_RECV_TIMEOUT, 1000000); // 1 second

Python

pymemcache

The pymemcache.client.base.Client accepts socket parameters as floating-point numbers representing seconds.

  • timeout: Sets the default socket read and write timeout.
  • connect_timeout: Sets the timeout for opening the socket connection.
from pymemcache.client.base import Client

client = Client(('127.0.0.1', 11211), connect_timeout=1.0, timeout=1.0)

pylibmc

The pylibmc library binds to libmemcached and exposes socket timeout configurations via behaviors:

  • receive_timeout: Read timeout in microseconds.
  • send_timeout: Write timeout in microseconds.
  • connect_timeout: Connection timeout in milliseconds.
import pylibmc

client = pylibmc.Client(
    ["127.0.0.1"],
    behaviors={
        "connect_timeout": 1000,
        "receive_timeout": 1000000,
        "send_timeout": 1000000,
    }
)

Java

Spymemcached

In Spymemcached, timeouts are applied on an operation level rather than an isolated raw socket layer, using the ConnectionFactoryBuilder.

  • setOpTimeout(long timeout): Governs the default operation timeout in milliseconds, which enforces the deadline for sending and reading responses.
  • setTimeoutExceptionThreshold(int): Controls the threshold of consecutive timeouts before a node is considered dead.
ConnectionFactory cf = new ConnectionFactoryBuilder()
    .setOpTimeout(1000) // 1 second read/write deadline
    .build();
MemcachedClient client = new MemcachedClient(cf, AddrUtil.getAddresses("127.0.0.1:11211"));

XMemcached

XMemcached handles read and write operations asynchronously via NIO, using configuration builders.

  • setOpTimeout(long timeout): Sets the operation response/read timeout in milliseconds.
  • setConnectTimeout(long timeout): Governs the TCP socket connection timeout.
MemcachedClientBuilder builder = new XMemcachedClientBuilder(
    AddrUtil.getAddresses("127.0.0.1:11211")
);
builder.setOpTimeout(1000);
builder.setConnectTimeout(1000);
MemcachedClient client = builder.build();

Go (gomemcache)

The standard Go client (github.com/bradfitz/gomemcache/memcache) simplifies timeout management into a single field on the Client struct.

  • Timeout: A time.Duration value that sets the socket read and write deadlines (SetDeadline) for all network operations.
package main

import (
    "time"
    "github.com/bradfitz/gomemcache/memcache"
)

func main() {
    mc := memcache.New("127.0.0.1:11211")
    mc.Timeout = 1 * time.Second // Applied to socket reads and writes
}

Node.js (memcached)

The popular memcached package handles connection timeouts during client instantiation using milliseconds.

  • timeout: Determines the amount of time in milliseconds to wait before a socket read/write operation is declared timed out.
  • idle: The time after which an inactive socket will be closed.
const Memcached = require('memcached');

const memcached = new Memcached('127.0.0.1:11211', {
    timeout: 1000, // Socket response timeout in ms
    idle: 5000
});
