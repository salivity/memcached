How to Set Memcached Daemon User Identity

This article covers the specific command-line argument used to set the user identity for the Memcached daemon, explaining how it functions and why it is critical for system security. By default, running network services with elevated privileges poses significant security risks, and Memcached includes built-in safeguards that require specifying an unprivileged user when starting the service as root.

The -u Flag

The command-line argument that controls the user identity under which Memcached runs is the -u option (short for "user").

When you start the Memcached binary, you supply the target username or user ID directly after the flag:

memcached -u <username>

For example, to run Memcached under the standard memcache service account:

memcached -d -u memcache -m 1024 -p 11211

In this command:

  • -d tells Memcached to run as a daemon (in the background).
  • -u memcache forces the process to switch to the memcache user.
  • -m 1024 allocates 1024 MB of memory.
  • -p 11211 sets the listening port.

Security Requirement When Running as Root

Memcached is designed to prevent accidental execution with administrative permissions. If you attempt to execute memcached as the root user without specifying a user identity, the daemon will refuse to start and will return an error stating that running as root is not permitted without the -u switch.

When invoked with -u by root, the daemon initializes necessary sockets and immediately drops its root privileges using the system's setuid() and setgid() calls, switching execution context to the designated user (commonly nobody or a dedicated memcache account).

Configuration Files

If Memcached is managed through an init system such as systemd or SysVinit, this argument is usually maintained in a configuration file:

  • Debian/Ubuntu (/etc/memcached.conf): Defined on its own line as -u memcache.
  • RHEL/CentOS (/etc/sysconfig/memcached): Defined within the environment variables as USER="memcached", which the startup script parses and appends as -u memcached to the daemon command.
