Monitor Memcached Hit-to-Miss Ratio via CLI

This article explains how system administrators can check and monitor the cache hit-to-miss ratio of a Memcached instance directly from the command line. By querying internal Memcached telemetry using native utilities like Netcat, Telnet, and memcached-tool, you can retrieve get_hits and get_misses statistics and calculate your cache's efficiency in real time.

Understanding Hit-to-Miss Metrics

Memcached tracks all read requests through internal counters:

  • get_hits: The number of times requested keys were found in the cache.
  • get_misses: The number of times requested keys were not found in the cache.

The hit ratio is calculated using the formula:

\[\text{Hit Ratio} = \left(\frac{\text{get\_hits}}{\text{get\_hits} + \text{get\_misses}}\right) \times 100\]

A high hit percentage indicates efficient cache utilization, while a low percentage suggests that keys are expiring prematurely, the cache memory limit is too small, or queries are bypassing cached keys.

Method 1: Using Netcat (nc)

Netcat allows you to send the standard stats command to the Memcached TCP port (default: 11211) and filter for hit/miss metrics using grep.

echo "stats" | nc 127.0.0.1 11211 | grep -E "get_hits|get_misses"

Example Output:

STAT get_hits 84210
STAT get_misses 15790

Automating the Calculation via Awk

To automatically calculate and display the percentage in the terminal without manual math, pipe the output into awk:

echo "stats" | nc 127.0.0.1 11211 | awk '
/STAT get_hits/ {hits=$3}
/STAT get_misses/ {misses=$3}
END {
    total = hits + misses;
    if (total > 0) {
        printf "Hits: %d | Misses: %d | Hit Ratio: %.2f%%\n", hits, misses, (hits / total) * 100;
    } else {
        print "No requests recorded yet.";
    }
}'

Method 2: Using Telnet

For an interactive session, you can connect directly through Telnet:

  1. Open a connection:

    telnet 127.0.0.1 11211

  2. Type stats and press Enter.

  3. Locate the STAT get_hits and STAT get_misses lines in the returned list.

  4. Type quit and press Enter to disconnect.

Method 3: Using memcached-tool

On Debian, Ubuntu, and Red Hat distributions, the Memcached package includes a Perl utility called memcached-tool. It parses stats and displays them in a readable format.

Run the following command:

memcached-tool 127.0.0.1:11211 stats

Look for the lines labelled get_hits and get_misses in the output to review the cache performance.

Real-Time Monitoring with watch

To track cache activity live as traffic reaches the server, combine the Netcat command with the watch utility:

watch -n 2 'echo "stats" | nc 127.0.0.1 11211 | grep -E "get_hits|get_misses"'

This refreshes the metric count every two seconds, allowing you to observe shifts in traffic patterns, load tests, or cache invalidation events.
