How to Change the Memcached Default Port

By default, Memcached listens for incoming connections on TCP port 11211. This guide covers the specific command-line option used to change the default TCP listening port, demonstrates how to run the daemon on a custom port, and explains how to make the configuration persistent across system reboots.

The Command-Line Option: -p

The command-line option used to change the default TCP listening port of a Memcached server is -p (lowercase).

To specify a custom TCP port when starting Memcached directly from the terminal, append -p followed by your desired port number:

memcached -p 11222 -u memcached -d

In this command:

  • -p 11222: Sets the TCP listening port to 11222.
  • -u memcached: Specifies the user account to run the process (required when starting as root).
  • -d: Runs Memcached as a background daemon.

(Note: If you also need to change the UDP listening port, use the uppercase -U flag. Setting -U 0 turns off UDP listening completely).

Making the Port Change Persistent

Starting Memcached manually via the command line is useful for testing, but production servers typically manage Memcached via system services. To ensure the custom port persists after a system reboot, edit the service configuration file.

On Debian and Ubuntu

  1. Open the configuration file:

    sudo nano /etc/memcached.conf

  2. Locate the line specifying the port (default is -p 11211) and change it to your desired port:

    -p 11222

  3. Save the file and restart the service:

    sudo systemctl restart memcached

On CentOS, RHEL, and Fedora

  1. Open the configuration file:

    sudo nano /etc/sysconfig/memcached

  2. Locate the PORT variable and update its value:

    PORT="11222"

  3. Save the file and restart the service:

    sudo systemctl restart memcached

Verifying the Change

After starting or restarting the service, verify that Memcached is actively listening on the new TCP port using ss or netstat:

ss -tlpn | grep memcached

The output should display the custom port you configured under the Local Address column.
