How to Enable Unix Sockets for Memcached

Switching Memcached from standard TCP/IP networking to a Unix domain socket reduces CPU overhead, eliminates network stack latency, and improves security for local processes. This guide details the exact configuration changes required to disable TCP listening, specify a Unix socket path, configure file permissions, and apply these settings across common Linux distributions.

1. Edit the Memcached Configuration File

Memcached configuration files differ depending on the operating system.

  • Debian/Ubuntu: /etc/memcached.conf
  • RHEL/CentOS/Rocky Linux: /etc/sysconfig/memcached

Open the appropriate file in your preferred text editor with administrative privileges.

2. Configure Socket Directives

To switch communication exclusively to a Unix domain socket, you must disable the default TCP port and define both the socket path and its permissions.

On Debian/Ubuntu (/etc/memcached.conf)

Locate and comment out the default TCP port and IP binding settings:

# -p 11211
# -l 127.0.0.1

Disable TCP listening explicitly and add the socket settings by appending the following lines:

-p 0
-s /var/run/memcached/memcached.sock
-a 0770
  • -p 0: Disables listening on any TCP port.
  • -s <path>: Defines the absolute path to the Unix socket file.
  • -a <mask>: Defines the octal permissions for the socket file (e.g., 0770 or 0777).

On RHEL/CentOS (/etc/sysconfig/memcached)

Update the parameters inside the OPTIONS variable and set PORT to 0:

PORT="0"
USER="memcached"
MAXCONN="1024"
CACHESIZE="64"
OPTIONS="-s /var/run/memcached/memcached.sock -a 0770"

3. Configure Directory and User Permissions

The Memcached service must have permission to write to the socket's directory, and your connecting application (e.g., Nginx, Apache, PHP-FPM) must have permission to access the created socket file.

  1. Create the socket directory if it does not exist:

    sudo mkdir -p /var/run/memcached
sudo chown -R memcached:memcached /var/run/memcached

  2. Add your application's user (such as www-data or nginx) to the memcached group so it can access the socket under 0770 permissions:

    sudo usermod -aG memcached www-data

4. Restart and Verify the Service

Restart the Memcached service to apply the configuration:

sudo systemctl restart memcached

Verify that Memcached is running and that the socket file has been generated:

ls -l /var/run/memcached/memcached.sock

To confirm Memcached is no longer listening on TCP port 11211, run:

ss -tulpn | grep 11211

If the command returns no output, TCP communication has been successfully disabled and Memcached is operating solely through the Unix domain socket.
